  P44 IS REFUTED. There are directions ON THE CONE with Lambda = 0 and Gamma > 0,
  so the top root does not move at second order where the commutator does, and NO
  inequality Lambda <= -c Gamma can hold. The LINEAR shape is dead.
  What replaces it is not nothing. Along such a direction the root falls at order
  four while the commutator grows at order two, and the table above shows the two
  exponents pairing into a constant ratio (y_0 - y)/C^2 across a decade in t. So the
  commutator is still the right functional and the wrong power was assumed: the
  shape a proof should target is maxroot <= y_0 - c C^2, quadratic and not linear.
  The degenerate directions, which made the second-order test blind, are exactly
  where that distinction is visible, so they are the evidence rather than the
  obstacle.
