The second-order equation, solved symbolically for a general symmetric X.
  X - P X - X P = D^2 has (X - PX - XP)_{ij} = X_ij (1 - P_ii - P_jj), so a diagonal
  entry has coefficient 1 - 2 P_jj, which is -1 inside the support and +1 outside.
  vertex   in support                 forced X_jj
       0         True                       -g0_0
       0        False                        g0_0
       1         True                       -g1_1
       1        False                        g1_1
  So the diagonal of X is determined by D^2 with a sign, and the off-diagonal blocks,
  which are the only freedom, never touch a diagonal entry.

  A system whose augmented rank exceeds its coefficient rank has no solution, so no
  curve on the variety has that velocity: the direction is in the kernel of the
  linearisation and not in the tangent cone. The cross directions are in the cone, by
  the explicit rotations of code/curvature.py, so the cone omits D while the kernel
  contains it, and Q being quadratic it is not closed under addition either. The
  commuting point is
  a singular point of the tight projection variety, for every commuting tight family
  containing two hyperedges through a common vertex and a vertex outside both.
